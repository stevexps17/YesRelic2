# YesRelic2 单人版 0.1.1

为《杀戮尖塔 2》独立实现的 Yes! 遗物模组，灵感来自 rael_kid 的一代 YesRelic。

适配本机 v0.111.0。当前是供实机验证的初版，不是已完成全部游戏内测试的正式版。

## 安装

1. 退出游戏。
2. 解压压缩包，将整个 `YesRelic2` 文件夹放入游戏的 `mods` 目录。
3. 本机安装后应存在以下文件：

   `C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2\mods\YesRelic2\YesRelic2.dll`

   `C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2\mods\YesRelic2\YesRelic2.json`

4. 启动游戏，在游戏内启用模组。若游戏提示需要重启，按提示重启。
5. 按 **F9** 打开设置，随后新开一局单人游戏。

本次没有自动安装到正式游戏目录。压缩包不包含游戏本体、测试副本或崩溃报告程序。无需 BaseLib 或 RitsuLib。

## 功能与具体效果

| 功能 | 本版规则 |
| --- | --- |
| Yes! 遗物 | 持有后，战斗卡牌奖励可逐张选择，最多拿完当前显示的全部卡牌。不会凭空增加候选牌。 |
| 自由结束 | 未拿牌时可跳过；拿过牌后显示“完成选择”，放弃剩余牌。 |
| 额外初始遗物 | 默认开启。新局额外获得 Yes!，保留角色原有初始遗物。不会自动补发给已经开始的旧局。 |
| 共享普通遗物池 | 默认关闭。开启后按普通遗物规则参与抽取，所有角色共用；已持有时不重复抽到。测试此项请关闭开局获得并新开一局。 |
| 无限次数 | 默认模式。只要持有遗物，每场战斗的卡牌奖励都可以多选。 |
| 有限次数 | F9 开启，初始次数可设 1–999，默认数值 3。遗物上显示剩余次数。 |
| 扣次时机 | 同一组奖励中成功拿到第 2 张牌时，才消耗 1 次。只拿 1 张、完全跳过不消耗。 |
| 同场奖励共享 | 同一场战斗出现多组卡牌奖励时，共用一次多选额度。即便最后一次已扣到 0，该场战斗的其他奖励组仍可多选。 |
| 次数耗尽 | 下一场战斗恢复正常的一组选 1 张，遗物保留。 |
| 存档 | 剩余次数、当前战斗计数以及本场是否已扣次数随遗物保存。 |
| 设置生效 | 开局选项影响新局。次数设置影响以后新获得的遗物，不改写已有遗物的次数。普通池选项影响后续可抽取资格。 |
| 单人限制 | 单人游戏生效，联机不发放初始 Yes!，不启用本模组多选逻辑。 |
| 适用范围 | 仅游戏标记为战斗来源的卡牌奖励；事件、商店来源奖励、删牌、升级、变牌不改变。 |
| 其他奖励按钮 | 拿过卡牌后只能继续拿或完成，不再允许用同组奖励换取跳过收益或重新抽牌。 |

原版公开说明可确认：战斗奖励任意多选、额外初始遗物、共享普通遗物池、可选次数限制，以及转经轮多组奖励共享一次的设计意图。
“只拿一张不扣次”“第二张成功入库才扣次”是此次移植明确采用的规则，未声称已核实一代实现。
原版评论里的主播投票/一键全拿属于请求，未确认已实现，本版不包含。

## 建议按顺序测试

### 1. 加载和默认开局

- 模组列表出现“Yes! 自由选牌（单人）”。
- F9 能打开设置；再次按 F9 或点击关闭可关闭。
- 开局获得、无限次数保持默认；新开一局。
- 预期：角色原有遗物仍在，额外出现 Yes!；悬停有中文描述，图标正常。

### 2. 无限多选

- 战斗胜利后打开卡牌奖励，先选 1 张。
- 预期：牌加入牌组，剩余牌仍可选，出现“完成选择”。
- 继续拿完全部牌。
- 预期：每张只加入一次，拿完自动返回奖励页，不卡住。
- 下一场只拿 1 张后点完成；再下一场完全跳过。
- 预期：牌组分别增加 1 张和 0 张；已完成奖励不能重复领取。

### 3. 有限次数（建议设为 2）

- F9 开启次数限制，设 2，保存后新开一局。
- 预期：Yes! 显示 2。
- 第一场只拿 1 张后完成：仍为 2。
- 第二场完全跳过：仍为 2。
- 第三场拿 2 张后完成：变成 1。
- 第四场拿完 3 张：变成 0，只扣 1 次。
- 第五场：正常只能拿 1 张。

### 4. 保存和继续

- 有限模式消耗一次后，走到下一层，正常保存并退回主菜单。
- 继续游戏。
- 预期：剩余次数没有重置，初始遗物没有重复发放，后续多选正常。
- 额外检查：在 F9 改次数不会立即改写当前遗物；新局会采用新设置。

### 5. 普通遗物池

- 关闭开局获得，开启普通池，保存后新开一局。
- 预期：开局没有 Yes!；后续可按普通遗物规则抽到，获得后多选生效。
- 随机掉落可能需要多次尝试，没马上遇到不表示失败。
- 若使用其他工具直接发放 Yes!，只能验证获得后的效果，不能证明随机遗物池有效。

### 6. 有机会时测试的边界

- 同场战斗两组卡牌奖励：两组都拿完，总共只扣 1 次；初始只剩 1 次时也应如此。
- 普通怪、精英、Boss 的战斗卡牌奖励分别测试。
- 事件或商店来源选牌保持原本规则。
- 获得卡牌时其他遗物的正常效果仍触发。
- 联机新局不获得本模组的初始 Yes!，不启用多选。
- 快速连续点击、键盘/手柄操作不应重复拿牌或卡住。手柄导航尚未实测。

## 0.1.1 语言更新

启动时自动跟随游戏语言。简体或繁体中文设置使用中文文案，英文及其他语言使用英文。F9 设置界面在游戏语言变化后自动刷新，遗物描述及完成按钮按游戏语言读取。无需单独选择模组语言。模组列表使用固定中英双语名称。

手动验证：英文启动后检查 F9 所有文字和遗物描述；改为中文后重新打开 F9；再切回英文。语言切换不应重置次数或未保存的选项。本次仅编译检查，未启动游戏。
